# Huishouden

Simple shared apps for running a home together, on everyone's phone and on a tablet in the
kitchen. *Huishouden* is Dutch for "household".

**Open it:** [huishouden-piekstra.web.app](https://huishouden-piekstra.web.app): one site, installed once,
with every app inside it. Free for any household: sign in with Google, start a household, invite the
people you live with. In English, Spanish and Dutch, light or dark.

## The apps

| App | |
|---|---|
| [Huishouden](https://huishouden-piekstra.web.app/) | Today, the calendar and the to-do list across every app, in one place |
| [Tasks](https://huishouden-piekstra.web.app/tasks/) | Shared to-dos and chores |
| [Groceries](https://huishouden-piekstra.web.app/groceries/) | What to get, and where it is |
| [Home](https://huishouden-piekstra.web.app/home/) | Keeping the house in good shape |
| [Bills](https://huishouden-piekstra.web.app/bills/) | What's due, and what's paid |
| [Spending](https://huishouden-piekstra.web.app/spending/) | Where the household's money goes |
| [Pet](https://huishouden-piekstra.web.app/pet/) | Caring for the animals in the family |
| [Baby](https://huishouden-piekstra.web.app/baby/) | Looking after the little one, together |
| [Health](https://huishouden-piekstra.web.app/health/) | Medicines and care for everyone at home |
| [Car](https://huishouden-piekstra.web.app/car/) | Keeping the cars on the road |

## Beyond the apps

| | |
|---|---|
| [Connector](https://huishouden-piekstra.web.app/assistant) | Use Huishouden from your own AI assistant (Claude, ChatGPT, Gemini CLI) |

## How it's built

Every app is made from one shared kit, so they look and work alike, and one set of rules decides
who in a household may see and change what. Each household's data stays in its own space, readable
only by its members and only as their role allows; helpers and kids see less. See the
[privacy page](https://huishouden-piekstra.web.app/privacy).
