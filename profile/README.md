# Huishouden

Simple shared apps for running a home together: on a tablet everyone passes in the kitchen, and on
everyone's phone. *Huishouden* is Dutch for "household".

| App | |
|---|---|
| [Huishouden](https://github.com/huishouden/portal) | Your household's apps, together in one place |
| [Spending](https://github.com/huishouden/spending) | Where the household's money goes |
| [Tasks](https://github.com/huishouden/tasks) | Shared lists and chores |
| [Baby](https://github.com/huishouden/baby) | Looking after the little one, together |
| [Home](https://github.com/huishouden/home) | Keeping the house in good shape |
| [Car](https://github.com/huishouden/car) | Keeping the cars on the road |

Free to use, for any household: sign in with Google, start a household, invite the people you live
with. Everything is built on one shared [kit](https://github.com/huishouden/pwa-kit), so the apps
look and work alike.
